## Codex Context Meter 交接链自动发现

- 开始任务前，如果当前工作目录存在 `HANDOFF.md`，先读取其中
  `CODEX_CONTEXT_METER_HANDOFF:START/END` 托管区块。
- 如果当前目录或项目内没有交接入口，再检查
  `%CODEX_HOME%\handoffs\HANDOFF.md`；`CODEX_HOME` 未设置时使用
  `%USERPROFILE%\.codex`。
- 交接区块可能指向完整链档案和索引。继续已有任务或用户明确要求恢复/接续时，
  必须完整读取被指向的 `chain-context.md`；内容较长时分段读完，不能只看最新快照。
- 项目内交接入口优先于全局入口。全局入口记录的 `workspacePath` 与当前工作目录
  不一致时，不要自动应用；只有用户明确要求恢复该任务时才读取。
- 用户开始一个无关的新任务时，不把旧交接内容当成本轮指令；可以保留发现结果，
  但不得让旧任务目标、待办或失效约束污染新任务。
- 旧交接中的已关闭或已替代事项必须作为历史保留和核对，但不得重新执行。
