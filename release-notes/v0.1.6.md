# v0.1.6

发布日期：2026-11-22

## 新增

- 团队看板按配置、`CODEX_TEAM_HOME`、Codex `config.toml` 和默认目录解析
  当前 `Team Home`。
- 打开或启动看板前校验 `/api/health` 返回的数据库路径，避免误连其他
  `Team Home` 的数据库。
- supervisor、PowerShell active-thread 和 Python watchdog 增加 Windows
  会话关机检测。

## 修正

- 修复关机过程中反复启动 `powershell.exe`、出现 `0xc0000142` 应用错误弹窗并
  阻塞关机的问题。
- 移除运行满 8 秒即强制回收 PowerShell 的逻辑，避免正常运行时持续重启进程。
- PowerShell 启动失败时记录错误并停止重试，不再形成高频重启循环。
- 明确计划任务只使用登录触发，避免分钟级重复拉起 widget。

## 验证

- Windows PowerShell 5.1 与 Python 语法检查通过。
- 关机保护单测确认禁止调用 `subprocess.Popen`。
- 启动失败单测确认 `OSError` 不再形成无条件重试循环。
- 卡死回收测试确认输出超时后仍会重建 active-thread。
- 运行观察确认 active-thread 超过原 8 秒阈值后 PID 保持稳定。
