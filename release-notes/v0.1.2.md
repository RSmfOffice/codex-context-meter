# v0.1.2 — 连续交接与完整上文

本版本规范了多对话交接格式，保证连续转接时不遗漏此前上下文。

## 新增

- 稳定 `chainId`：同一任务跨多个会话沿用同一交接链。
- `latest.json`：指向最新快照。
- `index.json`：完整顺序索引，包含 `coverageComplete=true` 和交接数量。
- `chain-context.md`：按时间累计全部交接内容，供新会话完整读取。
- MCP `context_meter_handoff` 工具：可写入摘要、决策、已完成、待办、验证、风险、文件和下一步。

## 交接保证

- 当前快照用于快速恢复，但不得单独作为完整上文。
- 新会话必须完整读取 `chain-context.md`；内容较长时要分段读完全部历史。
- 已失效事项仍保留，但会被标记为不得继续执行。
- 每次新增交接都会验证历史链覆盖完整性。

## 验证

- 10 项 Python 单元测试通过。
- Node MCP 两跳交接集成测试通过：第二次交接同时保留第一次和第二次摘要。
- 索引、完整链档案和最新快照均指向同一链。
