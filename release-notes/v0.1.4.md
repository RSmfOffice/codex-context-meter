# v0.1.4

发布日期：2026-11-07

## 新增

- 右键菜单“打开 Codex 团队看板”。
- 自动检测 `http://127.0.0.1:8765/api/health`。
- 看板未运行时，后台启动 `teamctl.py dashboard` 后再打开浏览器。
- 支持 `team_dashboard_url` 和 `team_board_root` 配置。

## 修复

- 浏览器启动、健康检查和后台进程拉起均在独立线程执行，不阻塞悬浮窗。
- 失败信息显示在 Tk 提示框，并写入 `%LOCALAPPDATA%\CodexContextMeter\team-dashboard.log`。
