# v0.1.0 — 首个公开版本

Codex Context Meter 是一个只统计当前单个 Codex 会话的 Windows 上下文悬浮组件。

## 主要功能

- 当前上下文占用圆环、剩余 token 和累计缓存命中率。
- 自动跟随 Codex 当前选中的聊天，不跨会话累加。
- Codex owner-window 层级、宿主跟随、拖动与位置记忆。
- 独立 Win32 跟随子进程，不占用 Tk 拖动和重绘路径。
- Codex 个人插件、MCP 状态/显示/停止工具和登录自动启动。
- 圆角原生窗口裁剪，无外围 DWM 阴影或矩形透明光晕。

## 性能与可靠性

- 会话目录查询使用短时缓存，65 个历史会话下缓存查询约 `0.0055ms`。
- UI 仅在数据变化时重建图像；稳定态主组件约 `0.47%` 单核 CPU。
- supervisor 可在大约 `730ms` 内恢复异常退出的组件。
- 点击 Codex 后通过命名事件唤醒 UIA，实测事件唤醒约 `33ms`。

## 系统要求

- Windows 10/11
- Codex 桌面版
- Python 3.11+、Pillow
- 插件安装另需 Codex CLI、Node.js 18+、Windows PowerShell 5.1+

## 安装

下载 `codex-context-meter-v0.1.0.zip`，解压后：

```powershell
python -m pip install -r requirements.txt
powershell.exe -NoProfile -ExecutionPolicy Bypass `
  -File .\codex-context-meter-plugin\scripts\install.ps1
```

首次安装后重启 Codex。
