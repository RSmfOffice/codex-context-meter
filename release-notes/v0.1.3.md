# v0.1.3 — 自动发现交接链

本版本解决新会话不会主动读取插件默认数据目录中交接文档的问题。

交接格式升级为 `handoff_version: 2`。

## 新增

- 从 `session_meta.payload.cwd` 自动识别当前工作目录。
- 在项目根维护可发现的 `HANDOFF.md` 托管区块。
- 在 `.codex/handoffs/codex-context-meter/` 镜像完整链上下文和最新快照。
- 无项目目录时写入 `%CODEX_HOME%\handoffs\HANDOFF.md`。
- 全局 `AGENTS.md` 增加自动发现、完整读取和防串任务规则。

## 发现顺序

1. 当前工作目录 `HANDOFF.md`。
2. 当前项目 `.codex/handoffs/codex-context-meter/`。
3. `%CODEX_HOME%\handoffs\HANDOFF.md`。

项目入口优先。全局入口记录 `workspacePath`，与当前工作目录不一致时不会自动应用。

## 安全更新

已有 `HANDOFF.md` 不会被覆盖；插件只替换带专用标记的托管区块，其他用户内容保持原样。

## 验证

- 10 项 Python 单元测试通过。
- MCP 集成测试验证有项目和无项目两种发现路径。
- 项目 `HANDOFF.md` 与全局回退入口均生成成功。
- 完整链镜像同时保留多跳交接内容。
